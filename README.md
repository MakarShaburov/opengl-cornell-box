# Лабораторная работа

## Тема

**Интерактивное взаимодействие с 3D-объектами в OpenGL: выбор и перемещение фигур с помощью мыши**

---

## Цель работы

Изучить возможности интерактивного взаимодействия с объектами трёхмерной сцены средствами OpenGL и GLUT.

Реализовать выбор 3D-фигуры с помощью мыши, изменение её цвета при выборе, перемещение объекта при зажатой кнопке мыши и восстановление исходного цвета после завершения перемещения.

---

## Постановка задачи

Необходимо разработать интерактивную 3D-сцену Cornell Box с несколькими объектами.

В рамках работы требуется реализовать:

1. Отображение трёхмерной сцены с использованием OpenGL.
2. Размещение в сцене двух прямоугольных блоков и стеклянной сферы.
3. Возможность выбора любой фигуры левой кнопкой мыши.
4. Изменение цвета выбранной фигуры на красный.
5. Возможность перемещения выбранной фигуры при зажатой левой кнопке мыши.
6. Перемещение объекта в плоскости, параллельной плоскости камеры.
7. Возвращение фигуры к исходному цвету после отпускания кнопки мыши.
8. Сохранение корректного отображения теней объектов при их перемещении.
9. Управление камерой и дополнительными параметрами визуализации с клавиатуры.

---

## Ход работы

### 1. Создание сцены

В качестве основы используется сцена **Cornell Box**.

Сцена содержит:

* стены комнаты;
* два прямоугольных блока;
* стеклянную сферу;
* источник освещения;
* тени от объектов;
* текстуру пола;
* возможность включения дополнительных эффектов визуализации.

Для создания и отображения сцены используются библиотеки OpenGL и GLUT.

### 2. Добавление выбора объектов

Для определения объекта под курсором мыши используется метод трассировки луча.

При нажатии левой кнопки мыши из положения курсора формируется луч, направленный в сцену.

Для блоков проверяется пересечение луча с их ограничивающими параллелепипедами (AABB), а для сферы используется проверка пересечения луча со сферой.

Основные функции:

```cpp
makeMouseRay()
raySphere()
rayAABB()
```

Если луч пересекает объект, он становится выбранным.

### 3. Изменение цвета выбранной фигуры

Для выбранного объекта используется отдельный цвет:

```cpp
float selectedColor[4] = { 1.0f, 0.0f, 0.0f, 1.0f };
```

При выборе объекта его обычный материал заменяется на красный.

После отпускания левой кнопки мыши выбор снимается, и объект снова отображается своим исходным цветом.

### 4. Перемещение объекта

Для обработки движения мыши используется функция:

```cpp
motion()
```

При перемещении мыши программа вычисляет положение курсора в мировых координатах.

Для этого используются лучи для предыдущего и текущего положения курсора.

Полученные лучи пересекаются с плоскостью, параллельной плоскости камеры.

За вычисление точки пересечения отвечает функция:

```cpp
rayCameraPlane()
```

После получения двух точек вычисляется смещение:

```cpp
vec3 delta = sub(p1, p0);
```

Полученное смещение применяется к выбранному объекту.

Таким образом, объект перемещается в направлениях, соответствующих движению курсора на экране.

### 5. Обработка кнопки мыши

Для обработки нажатия и отпускания кнопки используется функция:

```cpp
mouse()
```

При нажатии левой кнопки:

* определяется объект под курсором;
* объект становится выбранным;
* его цвет меняется на красный;
* включается режим перемещения.

При отпускании кнопки:

* перемещение завершается;
* объект перестаёт считаться выбранным;
* его исходный цвет восстанавливается.

### 6. Управление камерой и сценой

Помимо управления объектами с помощью мыши, в программе предусмотрено управление камерой и параметрами визуализации с клавиатуры.

Полный список управления:

| Клавиша   | Действие                                      |
| --------- | --------------------------------------------- |
| `↑` / `W` | Поворот камеры                                |
| `↓` / `S` | Поворот камеры                                |
| `←` / `A` | Поворот камеры                                |
| `→` / `D` | Поворот камеры                                |
| `2`       | Приблизить камеру                             |
| `3`       | Отдалить камеру                               |
| `Z`       | Включить/выключить разбиение полигонов        |
| `X`       | Включить/выключить текстуру пола              |
| `C`       | Включить/выключить тени                       |
| `V`       | Включить/выключить сглаживание (antialiasing) |
| `B`       | Включить/выключить стеклянный шар             |
| `R`       | Сбросить положение камеры                     |
| `Esc`     | Выйти из программы                            |

Также при запуске программы список управления выводится в консоль.

### 7. Перемещение разных объектов

В программе предусмотрена возможность перемещения трёх объектов:

* низкого блока;
* высокого блока;
* сферы.

Для блоков используются отдельные смещения:

```cpp
float shortOffset[3];
float tallOffset[3];
```

Для сферы изменяются её координаты:

```cpp
spherePos[0]
spherePos[1]
spherePos[2]
```

При перемещении блоков также учитывается их новое положение при построении теней.

---

## Управление

### Клавиатура

```text
↑ / W  — поворот камеры
↓ / S  — поворот камеры
← / A  — поворот камеры
→ / D  — поворот камеры

2      — приблизить камеру
3      — отдалить камеру

Z      — разбиение полигонов вкл/выкл
X      — текстура пола
C      — тени
V      — сглаживание (antialiasing)
B      — стеклянный шар

R      — сбросить камеру
Esc    — выход
```

### Мышь

| Действие              | Управление                         |
| --------------------- | ---------------------------------- |
| Выбрать объект        | Левая кнопка мыши                  |
| Перемещать объект     | Зажать левую кнопку и двигать мышь |
| Завершить перемещение | Отпустить левую кнопку             |

При выборе объекта его цвет меняется на **красный**.

## Результат

В результате была создана интерактивная трёхмерная сцена Cornell Box.

Реализована возможность выбора любой из трёх фигур с помощью левой кнопки мыши. При выборе объект меняет цвет на красный.

При удержании левой кнопки мыши выбранную фигуру можно перемещать по плоскости, параллельной плоскости камеры.

После отпускания кнопки мыши перемещение прекращается, а цвет объекта возвращается к исходному.

Кроме взаимодействия с объектами, реализовано управление камерой с клавиатуры, изменение масштаба просмотра и включение или отключение различных эффектов сцены: разбиения полигонов, текстуры пола, теней, сглаживания и стеклянной сферы.

---

## Вывод

В ходе лабораторной работы были изучены методы взаимодействия пользователя с объектами трёхмерной сцены в OpenGL.

Был реализован механизм определения объекта под курсором с помощью луча, изменение материала выбранного объекта и его перемещение с использованием координат мыши.

Также было реализовано управление камерой и параметрами отображения сцены с помощью клавиатуры.

В результате получена интерактивная сцена Cornell Box, в которой пользователь может управлять камерой, изменять параметры визуализации, выбирать объекты и перемещать их непосредственно с помощью мыши.
